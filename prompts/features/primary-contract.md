# Clima Weather App — Project Instructions

## Project Overview
Clima is a premium Flutter weather application.

The goal is to build a beautiful, responsive weather app with real-time weather information and forecasts.

## Technologies
- Flutter
- Dart
- Material 3
- REST API
- Open-Meteo API
- Google Fonts
- Riverpod (for state management, when introduced)

## Design Guidelines
- Premium dark navy theme.
- Blue and purple gradients.
- Modern glassmorphism cards.
- Rounded corners.
- Subtle animations.
- Beautiful typography.
- Responsive layouts.
- Consistent spacing.

## Architecture
Use a feature-based folder structure.

Keep:
- Screens separate from widgets.
- Models separate from UI.
- API logic inside repositories.
- State management separate from presentation.
- Reusable widgets in appropriate folders.

## Coding Rules
1. Write clean and readable Dart code.
2. Prefer reusable widgets.
3. Avoid unnecessary dependencies.
4. Use meaningful variable and class names.
5. Avoid unnecessarily large widgets.
6. Handle loading, success and error states.
7. Make layouts responsive.
8. Follow Flutter best practices.

## AI Development Rules
1. Inspect existing files before modifying them.
2. Never rewrite the entire application unnecessarily.
3. Explain important code changes.
4. Work one feature at a time.
5. Ask before making large architectural changes.
6. Identify potential bugs.
7. Run flutter analyze after significant changes.
8. Add tests for important business logic.
9. Never claim code works without testing it.

## Learning Requirements
The developer is returning to Flutter after a career break.

Explain important Dart and Flutter concepts in simple English.

Help the developer understand the code instead of blindly copying AI-generated implementations.
